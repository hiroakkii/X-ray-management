# 訪問患者リスト

Excelの患者マスタを取り込み、当日訪問する患者を検索・選択して一覧を印刷するブラウザアプリです。
サーバーやインストールは不要で、`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動作します。
データはブラウザ内で処理され、外部へ送信されません（ライブラリも `lib/` に同梱しているためオフラインで動作します）。
例外は「訪問ルート（地図）」機能を使ったときだけで、住所の文字列と地図の表示範囲のみが外部に送られます（下記）。

## 使い方

1. `index.html` をブラウザで開く
2. 「患者マスタ取込（Excel）」で患者マスタ（.xlsx / .xls / .csv）を選択
3. **取込内容の確認**画面で、Excelの各列がどの項目として取り込まれるかを確認する
   - 先頭行の題名（見出し）から自動判別します（「患者番号」→ID、「フリガナ」→ふりがな など）
   - 判別が違う場合は「取込先」のプルダウンで変更できます（変更した列は「手動」と表示）
   - 見出しが1行目でない場合（上に表題行がある等）は「見出しの行」を変更できます。先頭10行から自動推定もします
   - シートが複数ある場合はシートを選択できます
   - 下の「取込結果プレビュー」で、Excelの何行目がどのデータになるかを確認できます
   - IDの重複、日付として読めない生年月日などがあれば警告を表示します
4. 「患者検索」で患者名・ふりがな・ID・住所を検索（ひらがな/カタカナ、全角/半角は区別しません。スペース区切りで複数条件）
5. 検索結果のチェックを入れると「当日訪問リスト」に追加されます（行のクリックでも可。チェックを外すとリストから外れます）
6. 当日訪問リストの見出し（ID・ふりがな・患者名・性別・生年月日・年齢・住所）をクリックすると並べ替え（再クリックで逆順）。↑↓で個別に順番変更
   - グループホームの患者は居宅の患者と分け、ホームごとにまとめて表示・並べ替えします（居宅の前／後にまとめるかを選択可）
7. 訪問日・表題・生年月日の表記（西暦/和暦/併記）・用紙の向き（初期値 A4 横）を設定して「印刷」
   - 住所など長い文字は、セル幅に収まるよう文字を自動で小さくして印刷します（最小 6.5pt。それでも収まらない場合はセル内で折り返し）
   - グループホームの患者がいる場合は「居宅」「グループホーム○○」の見出し行で区切って印刷します

一覧・印刷の列順は 左から **ID、ふりがな、患者名、性別、生年月日、年齢、住所** です。
年齢は訪問日時点で生年月日から計算します（生年月日が無い場合はマスタの年齢列を使用）。

## 訪問ルート（地図）

当日訪問リストの患者を地図に表示し、効率のよい訪問順を計算します。

1. 「事業所（出発地）の住所」を入力し、往復（事業所に戻る）か片道かを選ぶ（住所が空欄なら出発地なしで計算）
2. **① 住所から位置を取得**：当日リストの住所を緯度・経度に変換して地図にピンを表示
   - 番地まで見つからない場合は番地までに短くして再検索します。見つからない住所は一覧の「地図で指定」から地図をクリックして指定します
   - 位置がずれている場合はピンをドラッグして直せます（次回からもその位置を使います）
3. **② 訪問順を計算**：移動距離（直線距離）が短くなる順番を計算し、地図に番号と経路を表示
   - 同じグループホームの患者は1か所としてまとめて計算します
   - 訪問先が8か所以下なら全通りを調べて最短を求め、それより多い場合は近似計算（最近傍法＋2-opt）です
   - 直線距離なので、川・線路・一方通行などは考慮しません
4. **③ この順番を当日リストに反映**：当日リストと印刷がこの順番になります（並び＝「訪問ルート順」）。グループホームの患者の直前にはホーム名の行が入ります
   - 見出しクリックで並べ替えると、元の「居宅とグループホームで分ける」表示に戻ります
5. 「Googleマップで経路を開く」：計算した順番でGoogleマップの経路を開き、道路に沿ったナビ・所要時間を確認できます（経由地が9か所を超える場合は複数のリンクに分割）

### 外部に送信されるもの

| 送信先 | 送る内容 | タイミング |
|---|---|---|
| 国土地理院 住所検索API（msearch.gsi.go.jp） | 住所の文字列（住所の列のみ。建物名などの「住所（続き）」は送らない） | ①を押したとき。取得済みの住所は再送信しない |
| 国土地理院 地図タイル（cyberjapandata.gsi.go.jp） | 表示している地図の範囲（患者の情報は含まない） | 地図を表示・移動したとき |
| Googleマップ | 住所（地図で指定した地点は座標） | 「Googleマップで経路を開く」を押したときのみ |

氏名・ふりがな・ID・生年月日・性別は送信しません。訪問順の計算はPC内で行います。
取得した位置はこのブラウザに保存されます（「保存データ消去」で一緒に削除）。

## 自動判別できる主な題名

| 項目 | 題名の例 |
|---|---|
| ID | ID、患者ID、患者番号、カルテ番号、患者コード、利用者ID |
| ふりがな | ふりがな、フリガナ、カナ、氏名カナ、よみがな |
| 患者名 | 氏名、患者名、患者氏名、名前、利用者名 |
| 性別 | 性別、性、男女（値は 1/2、男/女、M/F に対応） |
| 生年月日 | 生年月日、誕生日（Excelの日付、2000/1/2、20000102、昭和25年3月4日、S25.3.4 などに対応） |
| 年齢 | 年齢 |
| 住所 | 住所、現住所、所在地 |
| 住所（続き） | 住所2、番地、建物名、方書（住所の後ろに連結して表示） |
| グループホーム | グループホーム、グループホーム名、GH、施設名、入居施設（ホーム名の入力を想定。「○」「1」「有」などの印だけの場合は「グループホーム」として1つにまとめます） |

保険者番号・郵便番号・電話番号などの列は取り込みません。判別キーワードは `app.js` の `FIELDS` で変更できます。

## データの保存について

取り込んだ患者マスタと当日リストは、次回もすぐ使えるようにこのブラウザ（localStorage）に保存されます。
共用PCなどで残したくない場合は「保存データ消去」で削除してください。

## ファイル構成

- `index.html` / `style.css` / `app.js` … アプリ本体
- `route.js` … 訪問ルート（地図表示・位置の取得・訪問順の計算）
- `lib/xlsx.full.min.js` … Excel読込ライブラリ [SheetJS](https://sheetjs.com/) 0.18.5（Apache License 2.0、`lib/xlsx.LICENSE`）
- `lib/leaflet/` … 地図表示ライブラリ [Leaflet](https://leafletjs.com/) 1.9.4（BSD 2-Clause License、`lib/leaflet/LICENSE`）
- `sample/患者マスタ_サンプル.xlsx` … 動作確認用の架空データ（表題行・不要列・和暦の生年月日などを含む）
